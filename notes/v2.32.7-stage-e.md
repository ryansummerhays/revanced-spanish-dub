# Spanish Dub Study v2.32.7 Stage E

Stage E is the first real decoded-audio speech-analysis step after the safe PCM capture ladder.

## Proven input from v2.32.6

- AudioTrack write hook is stable.
- 48,000 Hz sample rate.
- 2 channels.
- Audio encoding 2 / PCM 16-bit.
- 3,840-byte write buffers (~20 ms at 48 kHz stereo PCM16).
- Sparse raw-byte reads and AudioTrack metadata probes reported zero errors.

## Stage-E scope

The existing `PlayerVolumePatch.observePcmBufferForStudy(ByteBuffer)` callback now performs bounded, allocation-free PCM16 analysis on the same duplicated ByteBuffer. It calculates RMS energy, peak magnitude, and zero-crossing rate, maintains a conservative adaptive noise floor, classifies voice-candidate buffers, and accumulates approximately one-second active/quiet windows.

This is deliberately **pre-clustering**. It does not yet decide Speaker A/B/C/D.

## Runtime success criteria

- playback remains stable
- `pcmVoiceEligibleBuffers > 0`
- `pcmVoiceDecodedFrames > 0`
- `pcmVoiceDecodeErrors == 0`
- `pcmVoiceWindows > 0`
- useful signal: `pcmVoiceCandidateBuffers > 0`
- on mixed speech/silence material, both `pcmVoiceActiveWindows` and `pcmVoiceQuietWindows` should ideally become nonzero

If those conditions hold, the next stage can move from speech activity into short independent diarization windows and speaker-feature/embedding clustering.
