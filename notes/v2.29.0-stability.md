# Spanish Dub Study v2.29.0 stability

This release intentionally keeps the v2.28 stock-Morphe v1.41.0 architecture and fixes only failures demonstrated by v2.28 runtime diagnostics.

- Restore the tested character-aware OpenRouter output token budget removed by the v2.27 stock reset.
- Publish only genuinely changed streamed translation slots, avoiding false target-language tail publication and rollback.
- Feed progressive translated snapshots into Morphe's existing Edge TTS prefetcher while preserving the live playhead.
- Drive paginated subtitle progress from actual Edge MediaPlayer position while Edge speech is active; hold page one during synthesis instead of advancing against silent video time.
- Keep local Android Visualizer speaker clustering diagnostic-only. It remains unsupported on the tested device/session and does not route voices in this release.
